DESKTOP AND MOBILE REVIEW — 22 NOVEMBER 2026
Branch: desktop-layout. Main is not modified by this work.
Review base: 6ea5a22, which removes desktop from main. This branch proposes
restoring the complete tested layout plus the chat and security corrections.
The combined app tree was checked to match the tested version exactly.

Pages and states checked in the browser
Housing, Tickets, Market, Groups; all four listing detail types; all four new
listing forms; edit an owned listing; own profile, edit profile, password,
notifications, courses, another student's profile; chats, archive, conversation;
missing listing; start, login, signup, verification, forgot and reset password.
23 signed-in route scenarios were checked at several widths, plus auth states.

Viewport observations
Actual page widths observed include 320, 354, 931, 1163, 1309 and 1745 CSS pixels.
The review found no whole-page horizontal overflow or server-error screens in
the completed route checks. Light/dark and empty/populated examples were used.
Desktop forms were visually checked for readable widths, card boundaries,
aligned controls and visible save buttons. The main chat scrolls independently.

Interaction checks
- Side chat closes/reopens in the same top-right location, outside adverts.
- A new incoming message appears in the chat overview without reloading.
- Unread navigation dots appear for new messages and clear after reading.
- New replies do not erase unsent text.
- Hidden mobile side chats remain unread until actually displayed.
- Expanded/collapsed chat groups and checkbox focus survive live updates.
- Registration using a disposable local account reaches verification and then
  the app; pasting the six-digit code fills all fields. No real email was sent.
- User choices, course restrictions and private-chat access remain enforced.

Automated validation
206 tests passed; 62 subtests passed. JavaScript syntax and diff checks passed.
Two existing FastAPI startup deprecation warnings remain.
New API checks cover unread counts/version changes, escaped previews,
private access, local links and no read-receipt side effects from polling.

Environment limits
All checks used local fake data. Live SMTP, production push delivery, paid AI
imports, hosted proxy/HTTPS and production storage need deployment smoke tests.
The notification page in this preview correctly reports push is not configured.
This report records tested behavior, not a guarantee that every possible bug
has been eliminated.

Branch split

security-only fix/audit-security-chat branch (PR #12). Review/merge #12 first,
then desktop-layout into main. Nothing is merged automatically by this move.
